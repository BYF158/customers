## 运行架构

```
浏览器 :9090 ─ nginx ─┬─ /             → /www/wwwroot/customer-visit/dist（Vue 构建产物）
                      └─ /api/         → 127.0.0.1:18080（Spring Boot）
                                              └─ MySQL 127.0.0.1:3307 / customer_visit
```

- nginx：站点配置 `/www/server/panel/vhost/nginx/customer-visit.conf`（新增文件，未改动其他站点）
  - 日志：`/www/wwwlogs/customer-visit.access.log` / `.error.log`
- 后端：`/www/wwwroot/customer-visit/app.jar`，端口 18080，仅绑定 127.0.0.1
  - 启动参数 `-Xms128m -Xmx256m -XX:MaxMetaspaceSize=160m`（实测 RSS ≈ 200MB）
  - 日志：`/www/wwwroot/customer-visit/logs/app.log`
- 数据库：复用本机 3307 实例（`/var/lib/mysql-zhice/my.cnf`，与面板 3306 实例互不影响）
  - 库：`customer_visit`；账号：`cvapp`（随机密码，见 `/www/wwwroot/customer-visit/conf/db.env`，权限 600）
- 前端：`/www/wwwroot/customer-visit/dist/`（来自仓库 `frontend/dist`）

## 启停

```bash
/www/wwwroot/customer-visit/cv-ctl.sh status    # 查看健康状态与端口
/www/wwwroot/customer-visit/cv-ctl.sh start     # 启动 MySQL(3307，若未起) + 后端
/www/wwwroot/customer-visit/cv-ctl.sh stop      # 只停后端，MySQL 保持
/www/wwwroot/customer-visit/cv-ctl.sh restart
```

> 没有配置开机自启；服务器重启后执行一次 `cv-ctl.sh start`。
> MySQL 3307 若被停掉，后端会连不上库，先 `cv-ctl.sh start` 即可。
