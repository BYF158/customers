# 原版 → 新版 功能对照

原版指 `BYF158/customers` 的 `拜访管理小程序-实时汇总版.txt`（单 HTML + localStorage + 可选 Supabase）。
下表逐项说明业务能力如何落到新系统。

## 1. 身份与权限

| 原版 | 新版 | 说明 |
|---|---|---|
| 顶部下拉「身份」切换客户经理 / 管理者 | 登录页账号登录，角色由后端返回 | 不再能随手切换成管理者 |
| 管理者密码存 localStorage，默认 123456 | 密码 BCrypt 存库，`/auth/password` 修改，管理员可重置 | 密码不出现在前端 |
| 管理者视角按会话内存变量 | JWT（默认 7 天）+ `@AdminOnly` 拦截 | 权限由接口层兜底 |
| 客户经理可改 URL 尝试访问管理功能（仅前端限制） | 管理接口返回 403 | 前后端双重校验 |

## 2. 数据层

| 原版 | 新版 |
|---|---|
| `DB = {managers[], plans[], visits[]}` 存 localStorage | 4 张 MySQL 表（见数据库设计） |
| Supabase 单行 JSON 覆盖式同步 | 事务写入 + 唯一约束；统计实时读库 |
| 计划 id = `经理_编码_月份` 字符串 | 自增主键 + `(manager_id, group_id, plan_month)` 唯一索引 |
| 集团名称随计划重复存储 | `customer_group` 主数据 |
| 月份固定 10/11/12 月 | `YYYY-MM` 任意月份 |
| 无重复记录约束（仅前端校验） | `visit_record.plan_id` 唯一 + 409 提示 |

## 3. 页面与操作

| 原版界面/功能 | 新版位置 | 改进 |
|---|---|---|
| 首页：完成率环、已/未拜访、集团数 | 首页 | 增加「本月待拜访」清单，点卡片直接登记 |
| 首页：各月完成情况 | 首页 + 统计页 | 统计页按年展示 12 个月 |
| 拜访页：快捷登记（选集团 + 月份） | 拜访页右下角「登记拜访」 | 直接列出待拜访计划，少一步选择 |
| 拜访页：集团清单 + 全部/未拜访/已拜访 | 拜访页 | 增加关键字搜索、月份筛选、分页/下拉刷新、管理员按经理筛选 |
| 拜访卡片 → 详情 → 登记/撤销 | 详情抽屉 | 增加「修改记录」（原版只能撤销重登） |
| 拜访表单：日期/方式/结果/记录 | 底部抽屉表单 | 日期用原生选择器；方式和结果为受控选项 |
| 统计页：总览、经理对比、月度、集团覆盖 | 统计页 | 增加按经理筛选（管理员）、导出入口 |
| 我的：数据概览 | 我的 | 保留 |
| 我的：Excel 导入（合并/替换） | 独立「数据导入」页 | 先预览校验、显示警告、导入结果显示自动建账号 |
| 我的：清单管理 | 独立「拜访清单」页 | 支持筛选、分页、编辑/删除 |
| 我的：绑定关系管理 | 「客户经理」+「拜访清单」 | 拆分职责：账号管理和计划分配分开 |
| 我的：恢复初始数据（清空全部） | 未保留 | 危险操作，改为按范围删除 + 数据库备份 |
| 我的：云端同步配置（Supabase） | 移除 | 数据已在服务端，天然多人共享 |
| 导出：拜访记录 / 完整备份 | 拜访/统计/我的 页均可导出 | 后端生成，手机可直接下载；可按经理、月份过滤 |
| 导入模板下载 | 数据导入页 | 月份列使用 `YYYY-MM`，可再导入 |

## 4. Excel 兼容性

| 原版格式 | 新版 |
|---|---|
| Sheet = 客户经理姓名 | 相同 |
| 表头含「集团编码」「集团名称」 | 相同 |
| 月份列：十月/十一月/十二月、10月、2026-10 | 全部支持，统一转 `YYYY-MM` |
| 单元格填任意值即视为有该月计划 | 相同 |
| 导入方式：合并 / 全量替换（清空全部计划和记录） | 合并 / 按范围替换（仅涉及经理+月份） |
| 同码不同名时后导入覆盖 | 保留库中名称并给出警告 |
| 未登记任何月份的集团：按当前月份处理 | 相同，并给出警告 |
| 导出两个文件（清单 + 明细） | 一个 xlsx，含各经理清单 Sheet + 拜访明细 Sheet |

## 5. 未保留 / 有意变化

1. **移除 Supabase 配置入口**：后端已经是唯一数据源，避免两套同步逻辑冲突。
2. **移除「恢复初始数据」**：容易误操作；改为按范围删除 + 数据库备份恢复。
3. **管理员不再是"免密视角"**：必须用 admin 账号登录，便于审计。
4. **身份不可随意切换**：换人使用需退出登录，避免记录归属混乱。
5. **拜访日期不能晚于明天**：防止误填未来日期影响「计划月内完成」统计（如需补录未来预约，可再放开）。
